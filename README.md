# 🍰 Dessert Recipes Animation

A modern Flutter application for discovering delicious dessert recipes with stunning animations, responsive design, Dark/Light mode support, Arabic & English localization, and a premium user experience.

---

## ✨ Features

### 🎨 Modern UI & UX
- Beautiful and responsive design
- Smooth animations and transitions
- Interactive recipe cards
- Elegant loading states and shimmer effects
- Dark & Light Theme support

### 🌍 Localization
- Arabic & English languages
- Full RTL support
- Dynamic language switching

### 🍩 Recipe Experience
- Detailed recipe information
- Ingredients checklist
- Step-by-step cooking instructions
- Cooking progress tracking
- Favorites management
- Recently viewed recipes
- Smart shopping list

### ⚡ Advanced Animations
- Hero Animations
- Circular Theme Reveal
- Floating Image Effects
- Staggered List Animations
- Interactive UI Feedback
- Confetti Celebration Effects
- Parallax & Ken Burns Effects

---

## 🏗️ Architecture

Built using a simplified Clean Architecture approach:

```text
lib/
├── core/
├── data/
├── presentation/
├── app.dart
└── main.dart
```

The project focuses on:
- Scalability
- Maintainability
- Separation of Concerns
- Reusable Components

## 🚀 Getting Started

Clone the repository:

```bash

```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
