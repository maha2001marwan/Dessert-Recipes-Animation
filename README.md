# Dessert Recipes — Flutter (Clean Architecture · Dark/Light · AR/EN)

## تشغيل المشروع
```bash
flutter pub get
flutter run
```

## البنية المعمارية (Clean Architecture, مبسّطة لحجم المشروع)
```
lib/
  core/                        # لا يعرف شيئًا عن الوصفات — بنية تحتية عامة فقط
    theme/
      app_semantic_colors.dart # ThemeExtension: كل ألوان الواجهة (فاتح/داكن)
      app_theme.dart           # ThemeData.light() / .dark()
      theme_controller.dart    # ChangeNotifier: الوضع الحالي + بيانات الـ Circular Reveal
    localization/
      app_localizations.dart   # نصوص الواجهة EN/AR بدون أي codegen
      locale_controller.dart   # ValueNotifier<Locale> بسيط
    utils/
      color_utils.dart         # ألوان أزرار تتكيف مع سطوع الخلفية
      responsive.dart          # حدّ أقصى لعرض المحتوى على الشاشات الواسعة

  data/                        # النماذج + البيانات + التخزين المحلي
    models/
      localized_text.dart      # نص ثنائي اللغة (en/ar) لأي حقل بيانات
      recipe.dart               # Recipe / Ingredient / RecipeStep / RecipeCategory
    datasources/
      mock_recipes.dart         # 11 وصفة بمحتوى كامل EN + AR
      favorites_local_datasource.dart # قراءة/كتابة المفضّلة عبر SharedPreferences

  presentation/                # كل ما يُعرض على الشاشة
    controllers/
      favorites_controller.dart # حالة المفضّلة في الذاكرة + مزامنة مع التخزين
    screens/
      recipe_list_screen.dart
      recipe_detail_screen.dart
    widgets/
      recipe_card.dart
      recipe_header_delegate.dart
      hero_flight.dart
      staggered_fade_slide.dart
      expanding_underline.dart
      shimmer_box.dart
      skeleton_recipe_card.dart
      category_filter_bar.dart
      theme_reveal_layer.dart
      ingredient_tile.dart
      step_tile.dart
      recipe_image.dart

  app.dart   # ربط الثيم/اللغة/المفضّلة بـ MaterialApp
  main.dart  # نقطة الدخول فقط
```

كل طبقة تعرف فقط ما تحتها: `presentation` تعرف `data` و`core`، لكن `data` و`core` لا يعرفان شيئًا عن
الواجهات. لا توجد ألوان أو نصوص ثابتة داخل أي widget — كل شيء يُقرأ من `Theme.of(context)` أو
`AppLocalizations.of(context)`.

## الوضع الداكن/الفاتح + Circular Reveal
- كل الألوان الدلالية مجمّعة في `AppSemanticColors` كـ `ThemeExtension` حقيقي.
- ألوان العلامة التجارية للوصفات ثابتة عمدًا بين الوضعين.
- عند الضغط على زر تبديل الثيم، دائرة تتوسّع من موضع الزر نفسه (`ThemeRevealLayer`) تكشف الوضع الجديد
  تدريجيًا — بدون أي التقاط صورة (screenshot)، فقط قناع دائري عكسي (`Path.combine(difference)`) يتقلّص
  فوق الوضع القديم.

## العربي/الإنجليزي + RTL
- نصوص الواجهة في `AppLocalizations` (خريطة بسيطة بدون أدوات توليد كود).
- محتوى الوصفات بالكامل (عنوان، وصف، مكوّنات، خطوات) مُترجم عبر `LocalizedText`.
- `flutter_localizations` يفعّل RTL تلقائيًا عند اختيار العربية؛ كل التموضعات تستخدم
  `PositionedDirectional` / `AlignmentDirectional` / `EdgeInsetsDirectional` بدل `left/right` الثابتة.
- زر الرجوع يبدّل اتجاه السهم (⇦/⇨) تلقائيًا حسب اللغة.

## التصميم المتجاوب
على الشاشات الواسعة (تابلت/ويب/سطح مكتب) يُحصر المحتوى بعرض أقصى (520) ويُوسَّط
(`Responsive.centeredMaxWidth`) بدل أن تتمدد الكروت بشكل غير مقروء.

## إمكانية الوصول (Accessibility)
تكبير الخط من إعدادات النظام مدعوم لكن محدود بحد أدنى/أقصى آمن (0.85–1.25) عبر `MediaQuery`
مخصصة في `MaterialApp.builder`، كي لا تنكسر العناصر ثابتة الحجم (البادجات، صفوف المكوّنات، الأزرار
الدائرية) عند تكبير مبالغ فيه، مع إبقاء تجربة قراءة أوضح لمن يحتاجها.

## ملخص كل الحركات والإضافات المنفذة
- **Hero مزدوج** (الطبق + خلفية الكرت الملوّنة) مع `flightShuttleBuilder` مخصص: دورة 360° + ارتداد/Spring
  حقيقي، وتحوّل تدريجي لزوايا الخلفية من مستديرة بالكامل إلى مستديرة من الأسفل فقط.
- **Circular Reveal عند تبديل الثيم** من نقطة الزر نفسه.
- **Staggered entrance للكروت** بالقائمة، مع إعادة تشغيل تلقائي عند تغيير الفلتر (بفضل `ValueKey(recipe.id)`).
- **Ripple حقيقي + Press-scale + Haptic** عند الضغط على أي كرت.
- **دوران + Parallax للأطباق** أثناء التمرير، محسوبان رياضيًا بدون RenderBox lookups.
- **Skeleton Shimmer**: أثناء تحميل الصور، وأيضًا شاشة كاملة من كروت شيمر عند فتح التطبيق لأول مرة/عند
  السحب للتحديث (`RefreshIndicator` مخصص).
- **فلاتر تصنيف** (الكل / كيك / فطائر / حلويات باردة) بشرائح متحركة أعلى القائمة.
- **Blur + Scale على القائمة** لحظة فتح التفاصيل (تركيز الكاميرا على الطبق الطائر).
- **Ken Burns Effect** على صورة الطبق بأعلى شاشة التفاصيل.
- **Sticky Mini Title** يظهر تدريجيًا بعد تقلّص الهيدر.
- **بادجات وقت التحضير وعدد الأشخاص** بدخول متدرّج.
- **تقييم بالنجوم** قابل للمس مع نبضة عند كل نجمة.
- **مكوّنات قابلة للتحديد** (Checkbox متحرك + خط يتوسط النص) وخطوات تحضير قابلة للإتمام (الرقم يتحول
  لعلامة ✓ بأنيميشن).
- **وضع "ابدأ الطبخ"**: زر عائم يفعّل شريط تقدّم حي (خطوات مكتملة/الإجمالي)، وزر إعادة تعيين.
- **مفضّلة محفوظة فعليًا على الجهاز** عبر `shared_preferences` — تبقى بعد إغلاق التطبيق.
- **مشاركة بصرية**: زر المشاركة يتحول لعلامة ✓ مؤقتة بعد الضغط (يمكن ربطه بحزمة `share_plus` لاحقًا
  بسطر واحد داخل `_handleShare`).
- **شريط الحالة (Status bar)** يتكيّف تلقائيًا حسب سطوع لون كل وصفة عبر `AnnotatedRegion<SystemUiOverlayStyle>`.
- **أزرار رجوع/مفضّلة/مشاركة تتكيّف تلقائيًا** مع سطوع لون الوصفة.
- **Staggered entrance حقيقي بالتفاصيل** (عنوان، بادجات، وصف، تقييم، كل قسم بخط سفلي متمدد، كل مكوّن/خطوة).
- عند الرجوع، كل الحركات تُعكس تلقائيًا لأن Hero يعكس نفس الـtween.

## تحديثات مطابقة لتحليل الفيديو المرجعي (دقيقة 1:1 مع ملف التحليل)
- **`FloatingImagePlate`** (ودجت جديدة مشتركة بين الكرت وشاشة التفاصيل): إطار أبيض حول الصورة الدائرية
  (4-6px)، لمعة زجاجية `RadialGradient` بالزاوية العلوية-اليسرى، وطفو مستمر مستقل عن أي تمرير (±5px
  كل 3.4-4.4 ثانية) مع ظل منفصل يتحرك بعكس اتجاه الصورة تماماً (يتمدد ويخف كل ما ارتفعت) — بالضبط
  المواصفة الواردة بالقسم 1.6 من ملف التحليل. كل صورة تاخذ `phase` مختلف حسب موقعها/فهرسها عشان
  القائمة كلها ما تطفو بنفس التوقيت بالضبط.
- **دخول الكروت الحساس لاتجاه السكرول** (القسم 1.3 و1.4 — "الفرق الأساسي"): الكرت يقرأ اتجاه
  التمرير لحظة ظهوره لأول مرة. لو المستخدم عم ينزل ↓ يدخل الكرت بفيد + انزلاق لفوق بسيط كالمعتاد. لو
  عم يطلع لفوق ↑ يدخل بانفراد/فتح ثلاثي الأبعاد (`rotateX` حول الحافة العلوية) بدل الفيد البسيط —
  تماماً نفس فكرة الـ perspective matrix الموصوفة بالتحليل، لكن معبَّر عنها بمصفوفة `Matrix4` مطبقة
  عبر `Transform` بدل حساب يدوي خارجي.
- **لمعة/بريق مرة واحدة على كل كرت** (`ShineSweep`, القسم 1.9): خط ضوء قطري يمر فوق الكرت مرة وحدة
  بعد دخوله، بتأخير مختلف لكل كرت (`index`-based) — مو متزامن، ومو مكلف أداءً لأنه يوقف الـ
  `ShaderMask` تماماً بمجرد ما تنتهي اللمعة.
- **فلاش أبيض لحظي قبل امتلاء لون الكرت** (القسم 1.5): تلميح بصري متعمد بدل اللاغ العرضي أثناء
  سكرول سريع — طبقة بيضاء تختفي بفيد فور ظهور الكرت.
- **دخول الصورة بعد التحميل بحركة "pop"** (`Curves.easeOutBack`, القسم 1.8): بدل ما تنط الصورة فجأة
  بعد التحميل.
- **عناصر زخرفية عائمة فعلياً بشاشة التفاصيل** (القسم 3.1): كل عنصر (🍃🍋✨) إله مدة وسعة وphase
  مختلفة شوي، بدل ما تكون ثابتة كما كانت.
- **تطبيق `FloatingImagePlate` نفسها على صورة الهيدر بالتفاصيل** مع تفعيل خيار الـ Ken Burns، فبتصير
  نفس صورة الكرت تماماً بصرياً (نفس الإطار الأبيض واللمعة) قبل الـ Hero وبعده — بدون أي قفزة شكلية.

## الجولة الثانية — كل أفكار "بنك الأفكار" (القسم 5) + ميزات جديدة لشاشة التفاصيل

### من بنك الأفكار بالتحليل (نُفّذت كلها)
- **Tilt تفاعلي باللمس** على كرت القائمة (فكرة #2): يميل الكرت بخفة مع سحب إصبعك ويرجع بحركة نابضة
  (`elasticOut`) عند الرفع — مبني على `Listener` بدل `GestureDetector` عشان ما يتعارض أبداً مع الضغط
  لفتح الوصفة.
- **تدرّج لوني للخلفية حسب أقرب كرت للسكرول** (فكرة #5): شريط توهج خفيف جداً أعلى القائمة يتحول بنعومة
  للون أقرب كرت مرئي.
- **دوران بسيط لدخول الصورة الدائرية** (فكرة #6): تدخل الصورة بلفة خفيفة (`rotateZ` من 0.16- إلى 0) مع
  فيد، منفصلة تماماً عن الطفو المستمر اللي يبلش بعدها.
- **Parallax بين طبقة اللون وطبقة الصورة أثناء الـ Hero** (فكرة #9): طبقة اللون توصل قبل الصورة بجزء
  من الثانية بدل ما توصلوا سوا بالظبط، يعطي إحساس عمق أثناء الانتقال.
- **بلور الخلفية أثناء الانتقال** و**Parallax الصورة الدائرية + دوران السكرول** (أفكار #7، #8، #1)
  كانت موجودة أصلاً بالمشروع.

### ميزات جديدة كاملة لشاشة التفاصيل (مو موجودة بالتحليل، إضافات مقترحة)
- **القيمة الغذائية لكل حصة**: أربع حلقات تقدّم متحركة (سعرات، بروتين، كربوهيدرات، دهون) تمتلئ بحركة
  متتالية. **ملاحظة مهمة**: التطبيق تجريبي بدون قاعدة بيانات غذائية حقيقية، فالأرقام مُشتقة بشكل ثابت
  من نوع الحلوى (`Recipe.nutritionEstimate`) — مو أرقام مقاسة فعلياً، موثّق بوضوح بالكود.
- **تعديل عدد الحصص حيّاً**: زر +/- بعداد متحرك (ينزلق لفوق أو لتحت حسب الاتجاه)، وكل كمية بقائمة
  المكوّنات تتحدث تلقائياً (`scaleIngredientText`) — مثلاً "2 cups" تصير "3 cups" عند رفع الحصص من 4
  لـ6.
  - **إفصاح مهم**: مقياس بسيط (يقرأ أول رقم بالنص ويضربه بالنسبة) — يشتغل صح مع أغلب صيغ المكوّنات
    الموجودة، بس ما "يفهم" وحدات القياس (مثلاً ما يحوّل 3 ملاعق صغيرة لملعقة كبيرة لما تكبر الكمية).
- **الأدوات اللازمة**: شرائح (chips) تدخل بتتالي سريع، مُشتقة من نوع الوصفة (فرن+خفّاقة للكيك، شوبك
  للفطائر، ثلاجة+خلاط للحلويات الباردة...).
- **نصيحة الشيف**: كرت قابل للطي/الفتح بحركة أكورديون سلسة. **إفصاح**: النصائح مُختارة من مجموعة عامة
  حسب فئة/معرّف الوصفة، مو مكتوبة يدوياً لكل وصفة تحديداً — نفس مبرر القيمة الغذائية.
- **"قد يعجبك أيضاً"**: شريط أفقي بوصفات من نفس الفئة أسفل الشاشة، كل كرت يدخل بحركة متتالية وينقلك
  لتفاصيل وصفة جديدة بانتقال مستقل.
- **بريق زر المفضلة**: عند الإضافة للمفضلة، ست قلوب صغيرة تتطاير للخارج وتختفي تدريجياً — نسخة مبسّطة
  من تأثير "Like button" (فكرة #15 بالتحليل).
- **تمدد الهيدر عند السحب الزائد**: سحب الشاشة لتحت من الأعلى (فوق أول عنصر) يكبّر صورة الوصفة قليلاً
  بشكل مطاطي بدل ما تحس إنها "ميتة" — تأثير iOS-style.

## أفكار لشاشات جديدة (اقتراحات فقط، لسا مو منفذة)
- **شاشة المفضلة**: كل الوصفات المحفوظة بشبكة/قائمة، بإمكانية إزالة بسحب جانبي.
- **قائمة تسوق ذكية**: تجميع كل المكوّنات "غير المؤشّرة" من عدة وصفات مفضلة بقائمة واحدة مصنّفة حسب
  النوع (بقالة، منتجات ألبان، إلخ) — تعتمد فعلياً على منطق `checkedIngredients` الموجود أصلاً.
- **وضع الطبخ ملء الشاشة**: بدل السكرول العادي، شاشة كاملة خطوة-خطوة بأزرار "التالي/السابق" وعداد وقت
  لكل خطوة (تبني على `cookingMode` الموجود أصلاً).
- **شاشة البحث**: بحث فوري بعنوان/مكوّنات الوصفات مع اقتراحات أثناء الكتابة.
- **شاشة "خطط أسبوعي"**: تقويم بسيط لجدولة وصفة لكل يوم بالأسبوع.
- **شاشة تقييمات/مراجعات المجتمع**: تعليقات وتقييمات من "مستخدمين" (mock) تحت كل وصفة.

## الجولة الثالثة — تفاصيل أنيميشن إضافية

- **خط شطب يرسم نفسه**: توشير مكوّن ما بيلغي النص فجأة — خط رفيع يكبر من جهة القراءة (يمين لشمال
  بالعربي) عبر النص، ويرجع يصغّر لو ألغيتِ التوشير.
- **عداد "متبقّي" حي** فوق قائمة المكوّنات، بيتحدث بانزلاق رقمي كل ما تتوشّري/تلغي مكوّن.
- **اهتزاز + بمضة لونية خفيفة** على قسم المكوّنات كامل (العنوان + القائمة) لو بدأتي "ابدأ الطبخ" وما
  زلتي ما وشّرتي ولا مكوّن — تنبيه لطيف، مو منع (وضع الطبخ بيبلش طبيعي برضه).
- **خط تقدّم عمودي** بجانب أرقام كل خطوة تحضير، يمتلئ بلون مميز لكل خطوة مكتملة — يعطي إحساس "تايم
  الاين" متصل بدل صفوف منفصلة.
- **نبضة هادئة** على الخطوة الحالية بوضع الطبخ (أول خطوة لسا ما خلصت) عشان تعرفي وين وصلتي بسرعة.
- **Ripple دائري** ينتشر من مركز صورة الوصفة بالهيدر كل ما توشّري خطوة جديدة بوضع الطبخ.
- **لون الهيدر يفتح تدريجياً** كل ما زادت نسبة إكمال الخطوات بوضع الطبخ.
- **احتفال Confetti** حقيقي (بدون مكتبة خارجية) لما تخلّصي كل خطوات الوصفة — قطع ملوّنة متطايرة بفيزياء
  جاذبية بسيطة.
- **زر المشاركة يطير**: الأيقونة "تنطلق" لفوق وتختفي قبل ما يظهر علامة الصح، بدل تبديل مسطّح.
- **Pull-to-refresh مخصص بشاشة القائمة**: بدل السبينر الافتراضي، أيقونة صحن صغيرة تدور مع مقدار السحب،
  وتستمر بالدوران أثناء التحديث الفعلي — مبنية بالكامل من صفر (`NotificationListener` + `ScrollEndNotification`) بدون أي حزمة خارجية.

**ملاحظة صادقة**: اقتراح "Skeleton→محتوى أنعم لشاشة التفاصيل نفسها" ما نفّذته — بيانات الوصفة بهاي
الشاشة موجودة محلياً وفورية أصلاً (مو async fetch)، فإضافة تأخير/skeleton مصطنع بيخلي التطبيق يحس أبطأ
بدون أي فايدة حقيقية. لو صار في مستقبلاً fetch فعلي من API، وقتها يكون منطقياً نضيفه.

## الجولة الثامنة — اكتشاف الإيماءات + شاشة splash + "شفتيه مؤخراً" + fallback أجمل للصور

### تلميح اكتشاف الإيماءات (سدّ فجوة استخدام حقيقية)
الجولة السابقة ضافت double-tap وlong-press بدون أي طريقة يعرف فيها المستخدم إنهم موجودين. صار:
- **بانر صغير بالقائمة الرئيسية** (مرة وحدة بعمر التطبيق) يشرح الـ long-press، قابل للطي بحركة سلسة،
  يختفي للأبد بعد أول ظهور (`HintsLocalDataSource` عبر `shared_preferences`).
- **فقاعة صغيرة بشاشة التفاصيل** تشرح الـ double-tap فوق الصورة، تختفي تلقائياً بعد 5 ثواني **أو** فور
  ما المستخدم يجرّب الإيماءة فعلياً (أيهما أسرع).
- كلا التلميحين مبنيين على widget واحد قابل لإعادة الاستخدام (`GestureHintBanner`).

### شاشة splash بسيطة

### "شفتيه مؤخراً"

(`RelatedRecipesCarousel`) بدل ما أبني وحدة جديدة من الصفر — أضفت له بس خيار عنوان مخصص.

### Fallback أجمل لفشل تحميل الصور
بدل مربع رمادي مسطّح بأيقونة شوكة-وسكينة ثابتة: تدرّج لوني ناعم (نفس ألوان الـ shimmer) + أيقونة كيك
تدخل بفيد وتتنفس بهدوء (breathing) بدل ما تبقى جامدة.

## الجولة الخامسة — فحص جودة شامل + تفاصيل أخيرة

قبل أي إضافة، عملت مراجعة كاملة للمشروع (43 ملف Dart):
- **توازن الأقواس** بكل ملف، وكشفت وأصلحت خطأين حقيقيين حصلوا أثناء التعديلات السابقة (سطر صف مفقود،
  ودالة يتيمة بلا تعريف).
- **تحقق من كل مفتاح ترجمة**: كل مفتاح مستخدم موجود بكلتا اللغتين، وكل مفتاح معرّف مستخدم فعلياً — ما
  في نصوص ميتة. لقيت 4 مفاتيح كانت معرّفة بس مو مستخدمة (`shared`، `rateRecipe`، `pullToRefresh`،
  `removedFromFavorites`) — حذفت الأول لأنه صار متجاوَز فعلياً (المشاركة بقت نسخ حقيقي)، والثلاثة الباقية
  وصلتها باستخدام حقيقي (تفاصيل تحت).
- **كل الـ imports النسبية** بالمشروع تم التحقق إنها مستخدمة فعلياً (مافي استيراد بلا فايدة).
- **كل استدعاءات `.clamp()`** (اللي بترجع `num` مو `double`/`int` بـ Dart) تم التأكد إنها محوّلة بشكل
  صحيح بكل مكان.

### تفاصيل جديدة من المراجعة
- **Undo عند إزالة المفضلة**: بدل ما تختفي الوصفة وخلص، صار في SnackBar فيه زر "تراجعي" يرجعها.
- **Semantics/accessibility**: تقييم النجوم وpull-to-refresh صار عندهم تسميات وصفية لقارئات الشاشة.
- **بمضة (pop) عند اختيار تبويب فلترة**: شريط الفلاتر (الكل/كيك/فطائر/بارد) صار كل شريحة توشير عندها
  ردة فعل فيزيائية (تكبير سريع + haptic) لحظة الاختيار، مو بس تغيير لون فلات.

## الجولة الرابعة — شاشتان جديدتان كاملتان + تفاصيل انتقال

### شاشة المفضلة (`favorites_screen.dart`)
- كروت كاملة بلون كل وصفة، بصورة `FloatingImagePlate` (نفس تأثير الطفو من الشاشة الرئيسية).
- إلغاء التفضيل من داخل الشاشة نفسها بيعمل **انكماش محلي سلس** (SizeTransition + fade) قبل ما ينفذ
  التغيير الفعلي — مو اختفاء فجائي.
- حالة فارغة بقلب ينبض بهدوء + زر "تصفّحي الوصفات" يرجعك للرئيسية.
- دخول متتالي (staggered) للكروت.

### شاشة قائمة التسوق (`shopping_list_screen.dart`)
- بتجمع **مكوّنات كل الوصفات المفضّلة**، مقسّمة كمجموعات قابلة للطي حسب كل وصفة.
- **الميزة الأبرز**: توشير عنصر ما بيشطبه بس — بيتحرك فعلياً (`AnimatedList` الأصلية من فلاتر، بدون أي
  حزمة خارجية) لآخر قائمة مجموعته، فالقائمة "تترتب" نفسها أثناء ما تتسوقي بالضبط متل ورقة حقيقية.
- عداد "X/Y" لكل مجموعة، وملخص عام "X عنصر · Y وصفات" أعلى الشاشة.
- حالة فارغة لو ما في وصفات مفضّلة بعد.
- **ملاحظة تصميم مهمة**: القائمة هاي مستقلة عن صناديق التوشير بشاشة تفاصيل الوصفة (تلك محلية وموقّتة
  لكل زيارة، مو محفوظة)، فقائمة التسوق عندها حالة توشير خاصة فيها.

### وصول للشاشتين الجديدتين
